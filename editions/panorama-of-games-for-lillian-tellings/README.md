## What changed

All 240 game vignettes and verdicts have been recomposed, along with each volume’s opening, interludes and ending. Every card has three new plain summaries. Printed alphabetical indexes now come near the front; the HTML has a direct genre selector and separately expandable practical notes and comic scenes.

The original researched factual fields, game identities, exact-edition records and source URLs were preserved by exact value comparison. No new game playthrough is claimed. The original Panorama and the source novels remain intact.

The complete manuscript contains 128,554 words including headings, metadata and source notes; 102,512 are comic/catalogue prose and rules. These six catalogue volumes are not six 50,000-word novels.

The six volumes’ new fictional passages contain 498 occurrences of the reclaimed in-group term (singular and plural); preface/rules are excluded from that measure. This is a descriptive measurement requested for the voice revision, not proof that a joke works.

## How to choose

Read the short pitch and main catch on two or three cards in a genre you want. A place to start means an editorially promising candidate; read the catch first flags a meaningful obstacle; a detour is a narrower or more demanding alternative. The 240 games include 33 promising candidates, 188 conditional entries and 19 detours. No label can decide whether you personally enjoy a game.

The offline evidence filters require explicit developer declarations from the inspected exact source record. Unknown evidence is excluded. Mouse-only may still require dragging, and a turn-based game may still have many menus. Full caveats stay on every card.

## Print and rebuild

PDFs use Letter paper with embedded fonts; print at actual size or fit to A4. EPUB permits reflow and larger type. The full edition is long: individual books are easier to handle. No physical print or specific e-reader device has been tested.

The self-contained source directory contains the six JSON books, front matter, sanitized evidence cache and builders. Run python work/build_panorama.py, python work/build_panorama_finder.py and python work/validate_panorama.py from source/. Python dependencies: reportlab, pypdf, pypdfium2 and Pillow; fonts default to Windows Georgia/Arial. PANORAMA_FONT_DIR can select an equivalent licensed font directory. Run node work/test_panorama_finder.cjs for routing checks. Rebuild outputs appear under outputs/ten-toes-down-panorama/.
